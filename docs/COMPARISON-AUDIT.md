# مقارنة المشروع القديم والجديد

المصدر المقارن: `../mudarris-platform-github`.
النسخة الجديدة: `mudarris-platform-next`.

## النتيجة

تمت مطابقة النماذج الأساسية وعددها 19، ومسارات المستخدم العامة والطالب والمدرس، وتدفقات التسجيل والدخول والاشتراكات والامتحانات والتقارير والملفات. الفروق التي ظهرت أثناء المقارنة كانت في سلوكيات إضافية داخل القوالب القديمة، وتم نقل أهمها إلى النسخة الجديدة.

## الفروق التي تم إصلاحها

- زيارة الدرس تسجل إكماله تلقائيًا كما في Django، مع الاحتفاظ بزر إلغاء الإكمال.
- لوحة الطالب تعرض الإحصائيات الأربعة، طلبات الاشتراك المعلقة، والاختبارات التي لم تُؤدَّ بعد، وسجل الدرجات والنتائج الأخيرة مع رابط مراجعة الإجابات والسجل الكامل.
- تفاصيل الامتحانات تعرض عدد الأسئلة والمدة ونسبة النجاح، كما تعرض تفاصيل الكورس عدّاد الدروس والاختبارات.
- الصفحة الرئيسية تعرض رابط واتساب المدرس عندما يكون مضبوطًا في إعدادات الموقع.
- لوحة المدرس تعرض روابط واتساب للطالب ووليي الأمر من ملف الطالب، ومن التقارير والرسائل.
- صفحة الحساب تعرض روابط ربط تيليجرام وقائمة الأجهزة المصرح بها للطالب.
- اسم بوت تيليجرام في روابط الربط يُقرأ من `TELEGRAM_BOT_USERNAME` بدل تثبيته داخل الواجهة.
- إدارة الدرس تعرض الكويزات المرتبطة به مع إنشاء كويز جديد وفتح إدارة الأسئلة مباشرة.
- التقرير الأسبوعي يستخدم أسبوع السبت إلى الجمعة، ويعرض الكورس المختار، كل المحاضرات والدروس، حالة المشاهدة، الدروس المشاهدة خلال الأسبوع، تفاصيل نتائج الامتحان والإجابات، وروابط واتساب.
- التقرير ينشئ رابط ولي الأمر الآمن ويحافظ على سجل المشاهدة.
- قائمة الطلاب في لوحة المدرس تعرض عدد الكورسات والامتحانات بجانب بيانات الحساب.
- حماية الفيديو تشمل مدة توقيع ساعة، فحص Referer، حظر أدوات التحميل المعروفة، وRange streaming مع `no-store`.
- فحص تعدد الشاشات يستمر أثناء جلسة الامتحان وليس عند البداية فقط.
- منع قائمة الزر الأيمن ورصد مفاتيح PrintScreen/Snapshot والطباعة في درس الطالب.
- إشعارات النتائج أصبحت تحتوي نسخة نصية مفصلة ونسخة HTML للبريد، وتشمل رابط النتيجة والتقييم ونسبة النجاح والإنذارات.
- تمت إضافة فحص إعدادات الإنتاج وأداة نسخة MySQL قابلة للتشغيل عبر `npm run check:production` و`npm run db:backup`.
- فحص الكاميرا متاح للزائر قبل تسجيل الدخول، كما في رابط Django القديم، مع ظهوره أيضًا داخل قائمة الطالب.
- قواعد المرفقات تمنع حفظ مرفق ملف بلا ملف أو مرفق رابط بلا رابط، وحذف الموارد يحذف الملف المرفوع المرتبط به.
- شاشة أكواد التفعيل تعرض فلترة الكورس والحالة وتصدر نفس النتيجة إلى Excel.
- لوحة المدرس تعرض الطلاب الجدد وآخر نتائج الامتحانات وعدد المحاولات، وتقارير المتابعة تدعم البحث والصف والكورس والتنقل بين الأسابيع ورصد فتح تقرير ولي الأمر.
- تم اختبار المسارات المصادق عليها في المتصفح: لوحة المدرس، التقارير، الأكواد، نموذج الكورس، تقرير الطالب، رابط ولي الأمر، وفحص الكاميرا العام.

## الوظائف المتطابقة بالفعل

- المستخدمون والأدوار وتحديث كلمات مرور Django القديمة إلى bcrypt.
- الصفوف والكورسات والمحاضرات والدروس والمرفقات.
- الاشتراكات المجانية والمدفوعة والأكواد الفردية والكود الموحد.
- يوتيوب وGoogle Drive والفيديو المحلي المحمي.
- أسئلة الاختيار والمقالي، التصحيح العربي، حفظ الإجابات، انتهاء الوقت، حد المحاولات، والتصحيح اليدوي.
- الكاميرا، ملء الشاشة، تبديل التبويب، المخالفات، قفل الحساب والحظر السنوي.
- نتائج الطالب والمدرس والتقارير وروابط ولي الأمر.
- الإعلانات والآراء ورسائل التواصل والأجهزة والإشعارات.
- رفع الملفات، تصدير الأكواد CSV/XLSX، وربط Telegram عبر `/start`.

## فروق متبقية أو تحتاج تحققًا

1. كاشف حجب عدسة الكاميرا يعتمد الآن على تحليل سطوع وتباين إطار الفيديو مع غياب الوجه، ويحتاج اختبارًا فعليًا على المتصفح لضبط العتبات وتقليل الإنذارات الكاذبة.
2. إشعارات البريد أصبحت غنية HTML، بينما Telegram وWhatsApp يستخدمان الرسالة النصية المفصلة نفسها. يلزم إعداد مزودي SMTP وUltraMsg وTelegram في بيئة التشغيل.
3. Django Admin القياسي لم يتم نسخه؛ تم استبداله بلوحة المدرس المخصصة التي كانت واجهة الإدارة الفعلية للنطاق.
4. تخزين الفيديو في النسخة الجديدة محلي افتراضيًا. الإنتاج يحتاج Object Storage أو قرصًا دائمًا مع نسخ احتياطية.
5. بناء الإنتاج تم التحقق منه من مجلد OneDrive على Windows. عند ظهور مشكلة صلاحيات مؤقتة في SWC، يمكن جعل المجلد متاحًا دون اتصال أو البناء من نسخة محلية غير متزامنة.

## آخر تحقق آلي

- `npm run typecheck`: ناجح للـAPI والواجهة.
- تم تشغيل فحوصات التكامل بعد آخر التعديلات ونجحت 22 حالة.
- `npm run build`: ناجح للـAPI وNext.js عند السماح لـSWC بقراءة مجلد OneDrive.
- `npm run db:backup`: نجح وأنشأ نسخة MySQL فعلية في `.local/backups`.
- فحص المتصفح اليدوي نجح للصفحة الرئيسية والكتالوج وتفاصيل الكورس وصفحة التواصل.
- فحص عرض الهاتف نجح، والقائمة المختصرة تفتح روابط التنقل المطلوبة.
